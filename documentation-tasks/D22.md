## 项目边界

NativeWeave独立于ArcForges，ArcForges只参考格式。C#是应用开发层，正式消费必须Native AOT。Database底层必须Rust，managed驱动只作源码/基准对照；Rust Server可选且需证据。优先源码驱动深度复用；普通新实体使用预编译native能力，不默认Cargo/CI。自然typed Fluent优先，不要求完整IQueryable/EF，不在C#重写SQL AST/方言。SG可选生成static metadata/DTO，不是唯一查询路径。Core只提供可组合ABI/lifetime/buffer/error/async，无巨型runtime。保留严格安全和生产验收，不授权大规模产品实现。

## 具体编制责任

细化既有ABI/lifetime/error，领域native对象不泄漏到Core。

Research输入：R03, R07, R10, R11。

### R03 — C ABI、布局与版本协商
- 比较稳定C ABI与native直接/批量操作；Rust AST/Value/trait私有布局不跨ABI；布局、版本、所有权分别验证。
- 整数宽度、bool/enum、结构体/union、UTF8切片和opaque handle如何编码；size/version字段如何演进；32/64位和调用约定的兼容边界
- 核验.NET11 UCO非blittable签名限制和fail-fast路径；Direct P/Invoke不遵循DefaultDllImportSearchPaths如何影响诊断与loader测试
固定来源见实际R evidence；引用不等于已读。

### R07 — 句柄、所有权、GC与父子资源
- 可变native builder的单writer admission不同于SafeHandle物理寿命；验证cross-query owner/dispose/inflight lease。
- 借用/拥有/共享资源的身份如何表达；SafeHandle和generation handle table何时需要；父子销毁、转移所有权和终结器如何互不冲突
固定来源见实际R evidence；引用不等于已读。

### R10 — Buffer、Pinning、批处理与数据传输
- Rust AST/value/batch与DTO复制成本；protocol credit不能释放managed仍持有的字节预算。
- 同步Span借用与跨async Memory租约如何区分；零拷贝是否降低总成本；池化、批处理与大对象如何有界
固定来源见实际R evidence；引用不等于已读。

### R11 — Error、panic、异常与故障隔离
- 错误码和消息谁释放；Rust unwind、panic=abort、OOM与外部异常各有何边界；C#异常如何在reverse P/Invoke处封闭
固定来源见实际R evidence；引用不等于已读。
