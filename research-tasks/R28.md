## Objective and phase

C# is the strongly typed application layer; Database/ORM queries and relations and the Server networking/protocol runtime must be implemented by mature Rust engines. Kestrel/managed drivers are comparators only. Ordinary Entity/DTO/Handler types use native modules precompiled by maintainers, with normal dotnet build/run and AOT; do not reimplement a C# SQL AST/dialects/full LINQ or introduce a mandatory monolithic Core runtime.

Only Research/Documentation and Design research prototypes are executed in the current phase; future Delivery implementation still requires explicit phase authorization. Design acceptance does not claim product, sustained-load or release validation has passed.
