## 目标与阶段

C# 是强类型应用层；数据库/ORM 查询关系和 Server 网络协议运行时必须由成熟 Rust 引擎实现。Kestrel/托管驱动只比较。普通 Entity/DTO/Handler 使用维护者预编译 native 模块，正常 dotnet build/run 与 AOT；不重写 C# SQL AST/方言/完整 LINQ，不引入强制巨型 Core runtime。

当前只执行 Research/Documentation 与 Design 研究原型；未来 Delivery 实施仍需明确阶段授权。设计接受不冒充产品、长负载或发布通过。

## 实际执行与异常路径

- 重复完成；丢失wake；token注册同步触发；完成后迟到取消；结果资源泄漏

1. 固定实际源码/版本/commit/crate checksum/features；仅列真正读过的符号与范围。
2. 区分上游测试已读、研究实验已运行、产品验证待实现；正常/失败/关键边界建立可追溯结论。
3. 适当实验保存完整命令、输入/输出 hash、目标平台、实际运行及保留失败；未执行不得标通过。
4. 明确技术决定、替代方案取舍和剩余产品义务，直接修正旧冲突，不只叠加附录。
5. 接受前独立技术审查精确输出，修复阻断，再绑定当前 graph subject 与真实证据。
