## Objective and phase

C# is the strongly typed application layer; Database/ORM queries and relations and the Server networking/protocol runtime must be implemented by mature Rust engines. Kestrel/managed drivers are comparators only. Ordinary Entity/DTO/Handler types use native modules precompiled by maintainers, with normal dotnet build/run and AOT; do not reimplement a C# SQL AST/dialects/full LINQ or introduce a mandatory monolithic Core runtime.

Only Research/Documentation and Design research prototypes are executed in the current phase; future Delivery implementation still requires explicit phase authorization. Design acceptance does not claim product, sustained-load or release validation has passed.

## Modules and interfaces

Sole owner of common logical metadata/table/column/projection IDs, scalar tags, limits, provider-neutral session/operation interfaces and outcome declarations in Data.Abstractions and native/database/interfaces. B09 owns query operation descriptors, B07 conversion implementations, B04 owning host. Do not define another metadata schema downstream.

C# interfaces:

DataSource/Session contracts; immutable Table<TEntity>/Column<TEntity,TValue>/Projection<T>; finite capability and limit profile; static materializer contract. Public names remain subject to ordinary API review, while ownership and wire semantics are fixed.

Rust native reuse:

Describe the selected Rust Engine capabilities without implementing a managed provider, SQL parser, SQL AST, dialect or driver.

## Implementation steps

1. Extract one canonical metadata schema from D14/D17: format version, content hash, table/column/projection stable IDs, names, codec, nullability, explicit keys and relation descriptors. ABI/package version remains separate from business metadata hash.
2. Declare one result-shape/row-lease interface consumed by B06/B12. Shape includes column count/order/IDs/aliases, type and nullability; missing nullable fields are not SQL NULL.
3. Specify physical Session single-command admission and cleanup control separately. Define independent outcome, protocol disposition and local lifetime states for B05; interfaces do not claim completion.
4. Generate or hand-author equivalent Rust/C# layout/golden fixtures from this one schema, with no whole Core metadata service. Reject duplicate IDs, unknown required codec/profile and checked length overflow.
