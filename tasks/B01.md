## 目标与阶段

C# 是强类型应用层；数据库/ORM 查询关系和 Server 网络协议运行时必须由成熟 Rust 引擎实现。Kestrel/托管驱动只比较。普通 Entity/DTO/Handler 使用维护者预编译 native 模块，正常 dotnet build/run 与 AOT；不重写 C# SQL AST/方言/完整 LINQ，不引入强制巨型 Core runtime。

当前只执行 Research/Documentation 与 Design 研究原型；未来 Delivery 实施仍需明确阶段授权。设计接受不冒充产品、长负载或发布通过。

## 模块与接口

Sole owner of common logical metadata/table/column/projection IDs, scalar tags, limits, provider-neutral session/operation interfaces and outcome declarations in Data.Abstractions and native/database/interfaces. B09 owns query operation descriptors, B07 conversion implementations, B04 owning host. Do not define another metadata schema downstream.

C# 接口：

DataSource/Session contracts; immutable Table<TEntity>/Column<TEntity,TValue>/Projection<T>; finite capability and limit profile; static materializer contract. Public names remain subject to ordinary API review, while ownership and wire semantics are fixed.

Rust 原生复用：

Describe the selected Rust Engine capabilities without implementing a managed provider, SQL parser, SQL AST, dialect or driver.

## 实施步骤

1. Extract one canonical metadata schema from D14/D17: format version, content hash, table/column/projection stable IDs, names, codec, nullability, explicit keys and relation descriptors. ABI/package version remains separate from business metadata hash.
2. Declare one result-shape/row-lease interface consumed by B06/B12. Shape includes column count/order/IDs/aliases, type and nullability; missing nullable fields are not SQL NULL.
3. Specify physical Session single-command admission and cleanup control separately. Define independent outcome, protocol disposition and local lifetime states for B05; interfaces do not claim completion.
4. Generate or hand-author equivalent Rust/C# layout/golden fixtures from this one schema, with no whole Core metadata service. Reject duplicate IDs, unknown required codec/profile and checked length overflow.

## 错误、取消、内存与并发

- Descriptor registration copies or retains an explicit owner before synchronous return; errors expose no partial registration or output owner.
- No borrowed span, arbitrary CLR type or application pointer survives await. Optional missing fields require an explicit version/default policy; they cannot silently decode NULL.

## 验收要求

- Cross-language metadata golden bytes and malformed inputs; wrong entity/value compile negatives; ABI/profile/version mismatch rejection before DB traffic.
- Public abstractions assembly loads without native runtime initialization; real host consumption is verified downstream, without forcing a managed fallback.

- ['Windows x64', 'Linux x64']
- ['ordinary dotnet build/run; for generators/analyzers this describes the produced consumer, not the compiler host', 'explicit-RID Native AOT publish and actual consumer execution on the required OS rows']
- Independent NuGet where this component is distributed; full no-Rust pristine consumer gates A16/B24.
- Exact source/lock/features/native/package/executable hashes; component tests cannot claim assembled product success.
- The task-specific cases below plus D04–D09; native and managed retirement separately observed.

依赖理由：No product task prerequisite: this is the one shared database seam, implementing accepted specifications. It must not depend on B09 or provider implementations.
