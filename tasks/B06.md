## 模块与接口

Own native cursor and owned row-batch implementation plus C# stream adapter; B01 owns shape/lease contracts and B12 owns DTO construction. Do not put DTO mapping inside drivers.

C# 接口：

IAsyncEnumerable<T> adapter or explicit Cursor.FetchAsync/OwnedRowBatch, with one active fetch and one untransferred result, explicit large-value chunks.

Rust 原生复用：

SQLx row streams/SQLite worker; native checked row codecs from B07. No unbounded fetch_all on the streaming path.

## 实施步骤

1. Maintain row and byte budgets together, including descriptor/cell/payload checked sizes. Stop adding a row before it exceeds the batch budget; use explicit chunk support or LargeValueRequiresStreaming for a single oversized field.
2. Shape-check count/order/IDs/aliases/type before first nullable read, then expose borrowed typed views only under the owned batch lease.
3. Transfer each completed batch at most once. Consumer break, cancellation or mapper exception closes the cursor and retains cleanup owners until protocol drain/retirement.
4. Use bounded batch/operation counts and bytes. Document SQLx PG Execute limit=0 and internal buffering so owned-batch limits are not represented as entire-RSS limits.

## 错误、取消、内存与并发

- Decoder/constructor failure releases the current batch, stops further fetches and cleans up cursor/session; do not free still-borrowed native bytes.
- Slow consumers apply admission backpressure; close/cancel may require provider cleanup after the enumerable has stopped yielding.
- All batch offset/length arithmetic is checked; malformed UTF8, unknown codec and NULL/nonnullable mismatch are structured failures.

## 验收要求

- Empty/one/multibatch results, huge field, slow consumer, early break, mapping throw and duplicate take/dispose through real PG/SQLite product paths.
- Assert bounded owned bytes and live owners separately from measured native driver/whole-process memory; downstream B22/B23 retain sustained RSS/workload gates.
- Windows/Linux AOT typed enumeration and clean NuGet consumer; no Span or borrowed pointer survives await/dispose.

- Windows x64; Linux x64
- ordinary dotnet build/run; for generators/analyzers this describes the produced consumer, not the compiler host; explicit-RID Native AOT publish and actual consumer execution on the required OS rows
- Independent NuGet where this component is distributed; full no-Rust pristine consumer gates A16/B24.
- Exact source/lock/features/native/package/executable hashes; component tests cannot claim assembled product success.
- The task-specific cases below plus D04–D09; native and managed retirement separately observed.

依赖理由：Preserve local implementation prerequisites; run composition acceptance with actual providers without blocking unrelated implementation work. The graph requires a DAG over start+acceptance: do not add a reverse accepted-status dependency to B04 or from B07 to its provider consumers. Native/component acceptance uses the real pinned upstream backend or a small ABI test fixture; the complete host AOT/NuGet composition is a downstream B04/B21/B24 gate with these exact component commits.
