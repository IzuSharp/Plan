## 项目边界

NativeWeave独立于ArcForges，ArcForges只参考格式。C#是应用开发层，正式消费必须Native AOT。Database底层必须Rust，managed驱动只作源码/基准对照；Rust Server可选且需证据。优先源码驱动深度复用；普通新实体使用预编译native能力，不默认Cargo/CI。自然typed Fluent优先，不要求完整IQueryable/EF，不在C#重写SQL AST/方言。SG可选生成static metadata/DTO，不是唯一查询路径。Core只提供可组合ABI/lifetime/buffer/error/async，无巨型runtime。保留严格安全和生产验收，不授权大规模产品实现。

## 可执行实现设计：成熟 Server 接缝与 managed handler 退休

B17 保持 selection_required=true、undecided。Kestrel 是必须研究的公平对照，产品 B15 也未选择；Rust 源码可绑定并不决定产品 host。未来选定后深度复用 Hyper Service/Body/connection、Tokio 与适用 Tower/Axum 层；Actix worker affinity 和 Pingora proxy 接缝作为独立比较，不把所有框架强塞成同一个运行时。

候选 ForeignService 在 Rust 接受 request head 和明确 owned body，分配有界 request/context slot，经 A07 的稳定 context 和有界 dispatcher 调用静态 C# handler。业务路由、DTO 和应用逻辑仍在 C#；Rust 保留网络/TLS/协议状态。不得在 native callback 内直接执行任意同步用户代码、持跨 ABI 锁等待 Task，或每个 chunk 无预算地 spawn 一个任务。

| 生命周期边界 | 必须保留的责任 |
| --- | --- |
| Request accepted | operation/request slot、request body、handler context 和取消关联均有 owner |
| Response head ready | 仅转移 head；body writer/reader、stream quota、retained Bytes 仍可能存活 |
| Body EOS/error/Drop | 结束 body 生产/消费并关闭相应许可，等待已有 retained frame 引用退出 |
| Handler unregister/host close | 关闭新准入，保持已有注册代际与 callback/control-call lease，驱动 native retirement |
| Native runtime timeout | 停止等待或隔离未退役工作，保留 callback roots；不得声称线程/任务/内存已全部释放 |

A07 负责 create/start/take/retire；本任务按 HTTP request/body 组合，不复制另一套跨语言异步桥。B16 负责共享预算语义与 tests；native adapter 暴露可测的 retained-frame、reservation、callback 和 context 计数。Tower 的响应 Future 许可与完整 response body 许可分离；H2 流控 credit 与真实 retained memory 分离。控制线程/执行器所有权，禁止框架无条件创建全局 Tokio 或同步桥套嵌 runtime。

必须有真实 HTTP 请求、body 流与 C# Native AOT handler：成功/异常/取消、head 前后失败、TLS 失败、迟到 response、unregister 重入、slow reader、大 chunk、permit 持有时 close、callback 卡住及 runtime timeout。分别固定 response/body/retirement 的事件顺序和资源计数 oracle。危险迟到 callback 负例隔离进程。与功能等价 Kestrel 基线对比完整端到端成本、协议差分、p99/RSS；不从小型 Rust probe 外推更快、零复制或产品完成。

Hyper Incoming 的 EndObserved 与精确 transport completion reason 分开；没有公开信号时报告能力受限，不把 None 当正常网络完成。Closing/retirement-pending 的 request/context 继续占用 A/request budget，不能因 head/Task 已完成而无限替换仍未回收的请求。
