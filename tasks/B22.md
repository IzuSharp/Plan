## 模块与接口

End-to-end failure/crash/soak correctness and bounded resource accounting of exact product composition.

C# 接口：

External fault driver and durable-data oracle; no in-process mock substitutes for server/database failures.

Rust 原生复用：

Real PostgreSQL/SQLite/native HTTP/TLS stack, process control and protocol fault proxy.

## 实施步骤

1. Inject lost COMMIT replies, failed transactions, early stream exit, slow readers, network reset, handler faults and shutdown races.
2. Reconcile database effects and session identity/state independently; differentiate rollback queued/acknowledged and worker retirement.
3. Run repeated load/drain/idle cycles and fixed-duration long workload with live owners/roots/permits/thread/RSS trends.
4. Record failure seed/timeline/build/DB identity and minimized reproduction; require no silent data loss/duplicate side effects.

## 错误、取消、内存与并发

- External timeout or process termination cannot be counted as graceful retirement.
- Flat RSS is not proof of no leak; leaked owner counters fail even when allocator returns no memory to OS.

## 验收要求

- All reference operations with real PG and SQLite plus native HTTP1/2/TLS on both AOT OS.
- Crash recovery, Unknown reconciliation, exhausted budget and shutdown liveness; explicit test duration/load and resource thresholds based on design limits.

- ['Windows x64', 'Linux x64']
- ['ordinary dotnet build/run; for generators/analyzers this describes the produced consumer, not the compiler host', 'explicit-RID Native AOT publish and actual consumer execution on the required OS rows']
- Independent NuGet where this component is distributed; full no-Rust pristine consumer gates A16/B24.
- Exact source/lock/features/native/package/executable hashes; component tests cannot claim assembled product success.
- The task-specific cases below plus D04–D09; native and managed retirement separately observed.
