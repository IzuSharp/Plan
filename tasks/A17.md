## 目标与阶段

当前只执行 Research/Documentation 与 Design 研究原型；未来 Delivery 实施仍需明确阶段授权。设计接受不冒充产品、长负载或发布通过。

## 模块与接口

Real synchronous Engine conformance using miniz_oxide codec category, not a byte-sum mock.

C# 接口：

Typed codec span/array/owned-buffer facade with explicit size limit.

Rust 原生复用：

miniz_oxide native zlib compression and bounded decompression; .NET ZLibStream is compatibility/cost oracle.

## 实施步骤

1. Wrap real pinned native algorithm in minimal C exports and explicit owner release; opt out of executor/callback capabilities.
2. Use fallible checked admission and bounded decompressor; state honest OOM/unwind limits and partial-output drop behavior.
3. Consume through generated facade and independent NuGet ordinary/AOT application.
4. Record incremental Engine code/dependency/package costs and compare direct Rust behavior without numerical superiority claims.

## 错误、取消、内存与并发

- Malformed or oversized/decompression-bomb inputs expose no partial owner; empty input handled explicitly.
- Synchronous algorithm does not advertise cancellation after the noninterruptible native call starts.

## 验收要求

- Direct Rust versus C# versus ZLibStream round-trip for varied sizes, malformed input and limit; creating allocator frees exactly once.
- Windows/Linux AOT and no global Tokio startup; independent app change preserves native hash.

- ['Windows x64', 'Linux x64']
- ['ordinary dotnet build/run; for generators/analyzers this describes the produced consumer, not the compiler host', 'explicit-RID Native AOT publish and actual consumer execution on the required OS rows']
- Independent NuGet where this component is distributed; full no-Rust pristine consumer gates A16/B24.
- Exact source/lock/features/native/package/executable hashes; component tests cannot claim assembled product success.
- The task-specific cases below plus D04–D09; native and managed retirement separately observed.

依赖理由：start pins only actually consumed completed modules; acceptance adds local assembled-runtime checks where required. Reference links alone never become a global barrier.
