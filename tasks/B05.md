## 模块与接口

Own transaction lifecycle/outcome/recovery and connection disposition policy in native/database/transactions; provider hooks remain B01 interfaces. Keep response-loss uncertainty out of generic Core status definitions.

C# 接口：

Typed transaction scope, CommitAsync result distinguishing Committed/RolledBack/Unknown, recoverable correlation data and explicit retry advice; no automatic replay of arbitrary business delegates.

Rust 原生复用：

SQLx transaction/savepoint/pool mechanics and native provider hooks. SeaORM TransactionTrait is only relevant to an explicit specialized profile, not mandatory for ordinary adapters.

## 实施步骤

1. Implement distinct state dimensions: transaction Active/CommitDispatched/Finalizing/Closed; durable outcome; protocol Reusable/NeedsDrain/Retire; local active leases/callbacks/retirement.
2. Record COMMIT dispatch before awaiting its response. Known confirmation chooses committed outcome; cancellation/error after dispatch with no definitive evidence remains Unknown.
3. Perform rollback/drain/probe through cleanup admission on the original session; release the pool permit only when the connection is reusable or physically retired.
4. Implement explicit savepoints and isolation capabilities. SQLite Deferred/Immediate mode is not a simulated PostgreSQL isolation matrix.
5. Expose application idempotency recovery using stable operation ID, tenant/key and request hash. Conflicting INSERT/SELECT in one Read Committed CTE can miss the winner; use a separate recovery SELECT after conflict.

## 错误、取消、内存与并发

- Drop queues rollback; it is not rollback confirmation. Subsequent cleanup, no-active-transaction response or connection close does not retroactively resolve an Unknown commit.
- Old cancellation generation and reused session must be isolated; rollback/drain failure means retire, not return to next tenant.
- Unknown can be durably recorded while local native/managed resources retire; keeping an undecidable business result does not require leaking the operation.

## 验收要求

- Actual product response-loss proxy forwards COMMIT and drops all reply frames after server durable completion; separate connection proves effect and client returns Unknown without retry.
- Same-session failed transaction rollback and reuse, dropped active transaction, savepoint recovery, acquire cancellation, pool close and stale cancel races on both providers.
- Cross-language model/oracle maps actual code transitions to C-TX invariants; finite state exploration does not claim weak-memory or soak proof.

- ['Windows x64', 'Linux x64']
- ['ordinary dotnet build/run; for generators/analyzers this describes the produced consumer, not the compiler host', 'explicit-RID Native AOT publish and actual consumer execution on the required OS rows']
- Independent NuGet where this component is distributed; full no-Rust pristine consumer gates A16/B24.
- Exact source/lock/features/native/package/executable hashes; component tests cannot claim assembled product success.
- The task-specific cases below plus D04–D09; native and managed retirement separately observed.
