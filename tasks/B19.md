## Modules and interfaces

Rust rmcp protocol with runtime tool metadata and static C# handlers/JSON metadata; optional package for consumers.

C# interfaces:

- Native runtime tool/resource/prompt descriptors, one ForeignMcp ServerHandler; get_info/supported_protocol_versions/list_tools/get_tool/call_tool.
- C# MapMcp(GeneratedTools.All,profile,JsonContext), typed application delegates and explicit auth checks.

Rust native reuse:

- rmcp3.10.0 StreamableHttpService<ForeignMcp,LocalSessionManager> Tower service and native model/transport.

## Implementation steps

1. Enable exact2026-07-28 no-legacy/no-event-store profile, JSON response, required protocol metadata, finite body/schema/string/depth limits.
2. Supply explicit Host/Origin allowlists with ports; Origin is not authentication and absence does not bypass auth.
3. Register runtime tools and exact get_tool schemas; schema-dependent SEP-2243 Mcp-Param-* checks do not equal general JSON Schema argument validation.
4. Map native-decoded arguments through bounded owned UTF8 buffers into typed static C# DTOs and back; charge double parse/encode temporaries and measure cost.
5. Keep native protocol/JSON-RPC/MCP errors distinct from tool execution error results and HTTP pre-parser failures.
6. No-event-store unfinished response disconnect cancels; persisted/replay/legacy profiles remain explicitly unsupported until separately specified and accepted.
7. Before public rmcp StreamableHttpService parses a body, apply D19/D07 native Tower preflight with budgeted wire buffer and serde Deserializer/DeserializeSeed/Visitor structural scan; reserve the source-justified worst live native/managed peak including SDK recollection/tree and DTO copies. No private expect_json call or handwritten parser; unproved profile bounds cannot be enabled.

## Errors, cancellation, memory and concurrency

- Unsupported version/tool/schema, header/meta mismatch, malformed JSON, body limit, auth failure and cancellation fail explicitly.
- Tool annotations are not authorization; expensive metadata generation happens before serving.
- Arbitrary JSON Schema validator is an explicit future capability choice, not falsely supplied by get_tool; current typed DTO validation is required glue.
