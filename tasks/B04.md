## Modules and Interfaces

Own mandatory native database host, Engine-local runtime, physical lease admission, resource tree and managed facade bridge. B01 defines seams; B02/B03 implement providers; B05/B06/B07 implement transaction/stream/codec components. Never define provider interfaces in B04 that the providers need before B04 exists.

C# interfaces:

DataSource.Open/Session acquisition and async execute facades; internal opaque SafeHandles and Operation<T>; no public Rust runtime or driver trait.

Rust native reuse:

Tokio runtime only within the async DB Engine, SQLx native pools, Core narrow owner/async primitives. Sync Engines elsewhere need not acquire this runtime.

## Implementation Steps

1. Bind create/start/request_cancel/typed take_result/try_retire/release with out owners null on failure and one successful transfer. Registration/start return and callback/control leases both participate in managed retirement.
2. Model DataSource closing and single-command Session admission explicitly. SafeHandle protects lifetime but does not authorize concurrent mutable Rust access.
3. Keep session/cursor/transaction/operation parent ownership until native cleanup finishes. A transferred cursor/batch owns an independent parent lease after operation retirement.
4. Expose bounded Engine-local runtime/pool configuration, shutdown deadline, diagnostics and reject-on-closing behavior; do not introduce a compulsory global Core executor.
5. Compose providers through B01 seam. Integrator connects workspace manifests; task worktrees must not each regenerate shared Cargo.lock or solution files.
6. Reuse A02 negotiated Engine loader/bootstrap and lifetime; do not implement a second module loader or capability protocol.

## Errors, Cancellation, Memory, and Concurrency

- Request cancellation never releases input, native context, parent lease or cancellation registration while access is possible.
- Close rejects new work but permits cleanup control; unconfirmed remote effect may remain Unknown after safe local retirement.
- A child owner outliving public parent disposal remains safely alive or fails new admission; finalizer performs no blocking async join.
