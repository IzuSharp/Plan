任务修订 **0.3.0**。所属图 `delivery-graph.json`；当前状态、精确来源 Commit 与接受记录以图为准。本文是现有114份独立任务说明之一。

## 目标与阶段

C# 是强类型应用层；数据库/ORM 查询关系和 Server 网络协议运行时必须由成熟 Rust 引擎实现。Kestrel/托管驱动只比较。普通 Entity/DTO/Handler 使用维护者预编译 native 模块，正常 dotnet build/run 与 AOT；不重写 C# SQL AST/方言/完整 LINQ，不引入强制巨型 Core runtime。

当前只执行 Research/Documentation 与 Design 研究原型；未来 Delivery 实施仍需明确阶段授权。设计接受不冒充产品、长负载或发布通过。

## 实施步骤

1. Record PE machine, exported symbols, CRT/system dependencies and exact MSVC/linker toolchain.
2. Run RID-free NuGet build/run and explicit win-x64 Native AOT outside source tree.
3. Transfer output to runtime-only matching Windows target and verify correct asset loading without source/build directories.
4. Preserve raw CRLF artifacts without silently normalizing hashes; separate observed-byte and repository-source identities.

## 错误、取消、内存与并发

- Wrong architecture/CRT/missing export fails with Engine/RID identity; no fallback to another system DLL.
- Managed GC/native threads/Dispose ordering are tested independently of Linux outcomes.
