## 目标与阶段

C# 是强类型应用层；数据库/ORM 查询关系和 Server 网络协议运行时必须由成熟 Rust 引擎实现。Kestrel/托管驱动只比较。普通 Entity/DTO/Handler 使用维护者预编译 native 模块，正常 dotnet build/run 与 AOT；不重写 C# SQL AST/方言/完整 LINQ，不引入强制巨型 Core runtime。

当前只执行 Research/Documentation 与 Design 研究原型；未来 Delivery 实施仍需明确阶段授权。设计接受不冒充产品、长负载或发布通过。

## 模块与接口

External reproducible performance/load controller and resource observation schema.

C# 接口：

Separate target executables: direct Rust, C# AOT+Rust and equivalent managed AOT comparator.

Rust 原生复用：

BDN/Criterion for labelled microbenchmarks, HdrHistogram or equivalent raw histogram support; OS/native/CLR counters.

## 实施步骤

1. Implement scheduled-arrival open-loop workload with separate dispatch/admission/completion times and generator saturation detection.
2. Keep failures/timeouts/rejections in datasets; preserve raw histograms/overflow and independent process repetitions.
3. Record exact hardware/ISA/power/OS/features/locks/artifact hashes, warm/cold cache/durability/TLS/serialization settings.
4. Collect managed/native allocations, copied bytes, owner/permit counts, RSS/private working set/thread stacks and engineering cost.
5. Predeclare workload cells and noise-based regression analysis; override BDN host-native ISA when testing portable releases.

## 错误、取消、内存与并发

- Coordinated omission, omitted timeouts or saturated load generator invalidate comparison cell.
- Unavailable counters are unknown, not zero; queue byte limit does not imply RSS cap.

## 验收要求
