## Modules and Interfaces

Own static managed typed readers and DTO construction/runtime contract. Read B01 row-lease interface and B07 scalar conversion; B06 owns batch allocation/cursor implementation, B10 optional emitted constructor code.

C# interfaces:

Static RowReader<T>/projection constructor interface, typed scalar access and lease scope; no identity map, reflection setter, arbitrary runtime generic instantiation or managed relation graph.

Rust native reuse:

Native provider/codec computes typed result values and shape; C# maps that finite representation directly to application DTOs. SeaORM dynamic projection is optional inside Rust and must obey identical shape checks.

## Implementation Steps

1. Validate expected shape count/order/IDs/alias/type/nullability before nullable getters. SeaORM Option<T> can map a missing SQLx column to None; guard that native path too.
2. Generate/implement direct typed scalar reads and constructor/member assignment. SQL NULL in a present nullable column is distinct from missing shape and from a nonnullable failure.
3. Scope every borrowed view to the owned batch lease; copying a retained CLR string/array is explicit. Do not return an escaping Span backed by already-released native memory.
4. Wrap constructor/setter/JSON reader exceptions in finally cleanup; cursor close and protocol cleanup remain asynchronous owners and are not abandoned on mapping failure.

## Errors, Cancellation, Memory, and Concurrency

- Wrong type/shape, narrowing/precision failure or constructor throw is a typed mapping failure with no partially published DTO result collection.
- Task completion/early enumeration stop does not prematurely release batch or parent; cancellation invokes the same B06 cleanup flow.
