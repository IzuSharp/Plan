## Objective and Phase

C# is the strongly typed application layer; database/ORM queries and relationships and Server networking/protocol runtimes must be implemented by mature Rust engines. Kestrel/managed drivers are comparison baselines only. Ordinary Entity/DTO/Handler code uses maintainer-precompiled native modules with normal dotnet build/run and AOT; do not reimplement a C# SQL AST/dialects/full LINQ or introduce a mandatory monolithic Core runtime.

The current scope is Research/Documentation and Design research prototypes only; future Delivery implementation still requires explicit phase authorization. Design acceptance must not be presented as successful product, long-running-load, or release acceptance.

## Modules and Interfaces

Own static managed typed readers and DTO construction/runtime contract. Read B01 row-lease interface and B07 scalar conversion; B06 owns batch allocation/cursor implementation, B10 optional emitted constructor code.

C# interfaces:

Projection<T>, RowMaterializer<T>, EntityWriter<T>, non-generic ref-struct RowReader/RowWriter, ResultColumn<T> and ResultField use typed codecs and owned DTO construction. No identity map, reflection setter, arbitrary runtime generic instantiation or managed relation graph.

Rust native reuse:

Native provider/codec computes typed result values and shape; C# maps that finite representation directly to application DTOs. SeaORM dynamic projection is optional inside Rust and must obey identical shape checks.

## Implementation Steps

1. Validate expected shape count/order/IDs/alias/type/nullability before nullable getters. SeaORM Option<T> can map a missing SQLx column to None; guard that native path too.
2. Generate/implement direct typed scalar reads and constructor/member assignment. SQL NULL in a present nullable column is distinct from missing shape and from a nonnullable failure.
3. Scope every borrowed view to the owned batch lease; copying a retained CLR string/array is explicit. Do not return an escaping Span backed by already-released native memory.
4. Wrap constructor/setter/JSON reader exceptions in finally cleanup; cursor close and protocol cleanup remain asynchronous owners and are not abandoned on mapping failure.
5. Public API refinement 0.4.0: Projection<T>/RowMaterializer<T>/owned DTO creation, nullability/cardinality and mapper-exception cleanup over B06 buffers.
6. Public API refinement 0.4.0: Use api_design_inputs and api_design_input_sha256 from the exact pinned Design commit; implement the declared member/type policies and native operation mapping. Update task-owned XML, generated API Reference contribution, guide and minimal/advanced consumer source together. For internal-only scopes document applicability and expose no accidental public plumbing.

## Errors, Cancellation, Memory, and Concurrency

- Wrong type/shape, narrowing/precision failure or constructor throw is a typed mapping failure with no partially published DTO result collection.
- Task completion/early enumeration stop does not prematurely release batch or parent; cancellation invokes the same B06 cleanup flow.
