## Modules and Interfaces

Logical admission gate plus physical native resource lease; SafeHandle alone is not the admission policy.

C# interfaces:

Private SafeHandle owner; TryAcquire/lease and Dispose/DisposeAsync with explicit lifecycle.

Rust native reuse:

Rust RAII owners/Arc as source semantics permit; creating module releases its own resources.

## Implementation Steps

1. Implement Open→Closing→Closed admission under one synchronization policy; acquire logical token and DangerousAddRef before exposing native pointer.
2. Roll back all earlier increments if a later acquisition fails; close admission atomically and let previously admitted calls finish.
3. Release physical lease and logical token exactly once in finally/RAII, including managed mapping/native errors.
4. Expose completion of true retirement separately from synchronous Dispose request; finalizer path must be bounded/nonblocking.

## Errors, Cancellation, Memory, and Concurrency

- No new admission succeeds after close linearization; a call holding an earlier admitted lease may enter/finish native code during Closing. No native release before every admitted lease ends.
- Double Dispose is idempotent but arbitrary double native release is a caller defect; avoid false reuse of recycled pointer identity.
