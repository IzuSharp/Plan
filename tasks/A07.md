## 模块与接口

Operation state machine: completion/cancellation/result ownership/retirement are separate.

C# 接口：

Task-based async API; ValueTask only when lifetime-safe reuse is proven; create/register/start handshake.

Rust 原生复用：

Pinned Engine Future/executor semantics plus Core callbacks; no runtime-independent Future ABI.

## 实施步骤

1. Create operation with callback admission closed, register managed cancellation/root, then start; already-cancelled token safely requests cancellation before or during start.
2. Atomically select one terminal result; request_cancel never replaces committed success/error and take_result transfers its owner once.
3. Publish terminal notification through bounded mailbox/sequence protocol with no lost wake; acknowledge delivery and hold result lease through DTO materialization.
4. DisposeAsync rejects new work, requests native cleanup, waits native quiescence and managed delivery retirement, then unregisters roots/releases handles.
5. Document synchronous completion and every failed create/register/start/queue/take path with current resource owner.

## 错误、取消、内存与并发

- Callback scheduling failure cannot lose an already committed terminal or free a still-live native operation.
- CancellationTokenRegistration disposal/reentrancy must not deadlock under callback locks; caller timeout preserves live cleanup owners.
