## 目标与阶段

C# 是强类型应用层；数据库/ORM 查询关系和 Server 网络协议运行时必须由成熟 Rust 引擎实现。Kestrel/托管驱动只比较。普通 Entity/DTO/Handler 使用维护者预编译 native 模块，正常 dotnet build/run 与 AOT；不重写 C# SQL AST/方言/完整 LINQ，不引入强制巨型 Core runtime。

当前只执行 Research/Documentation 与 Design 研究原型；未来 Delivery 实施仍需明确阶段授权。设计接受不冒充产品、长负载或发布通过。

## 实施步骤

1. Generate valid/invalid descriptors and compare native/C# outcomes to independent mathematical/reference oracles.
2. Use controlled barriers for every named boundary schedule in D04–D09 and enumerate the exact bounded model schedules selected for this implementation. Record operation/thread/queue/preemption bounds and untested schedules; separate managed GC scheduling from native owner counters and make no exhaustive unbounded-interleaving claim.
3. Run malformed boundary/crash negatives in isolated subprocesses with timeouts and saved seeds/minimized cases.
4. Declare exact sanitizer/model-supported subsets and carry unsupported full CLR FFI coverage through real target tests.

## 错误、取消、内存与并发

- Fuzz timeout/crash/OOM is retained failure/inconclusive, never silently discarded.
- Do not call arbitrary invalid raw pointer cases in a process whose survival is asserted.

## 验收要求

- Full offsets/extents/UTF8/status/owner transfer properties, duplicate/late callback and shutdown race schedules.
- No leaked outstanding owners after all acknowledged retirement; source/log/seed/tool hashes and independent failure triage.

- Windows x64; Linux x64
- ordinary dotnet build/run; for generators/analyzers this describes the produced consumer, not the compiler host; explicit-RID Native AOT publish and actual consumer execution on the required OS rows
- Independent NuGet where this component is distributed; full no-Rust pristine consumer gates A16/B24.
- Exact source/lock/features/native/package/executable hashes; component tests cannot claim assembled product success.
- The task-specific cases below plus D04–D09; native and managed retirement separately observed.

依赖理由：start pins only actually consumed completed modules; acceptance adds local assembled-runtime checks where required. Reference links alone never become a global barrier.
