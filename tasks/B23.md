任务修订 **0.3.0**。所属图 `delivery-graph.json`；当前状态、精确来源 Commit 与接受记录以图为准。本文是现有114份独立任务说明之一。

## 目标与阶段

C# 是强类型应用层；数据库/ORM 查询关系和 Server 网络协议运行时必须由成熟 Rust 引擎实现。Kestrel/托管驱动只比较。普通 Entity/DTO/Handler 使用维护者预编译 native 模块，正常 dotnet build/run 与 AOT；不重写 C# SQL AST/方言/完整 LINQ，不引入强制巨型 Core runtime。

当前只执行 Research/Documentation 与 Design 研究原型；未来 Delivery 实施仍需明确阶段授权。设计接受不冒充产品、长负载或发布通过。

## 实施步骤

1. Use A21 controller with B21 applications and B22 correctness oracles; keep DB durability/TLS/serialization/query semantics equal.
2. Measure cold/warm, small/large payload, low/high concurrency, streaming and overload with raw histograms and repeated processes.
3. Attribute FFI/DTO/copy/managed/native allocation and runtime threads, plus RSS/working set/package/build/application edit costs.
4. Report adverse/unsupported cells and confidence intervals; propose optimisations only with source/lifetime tradeoff and repeatable benefit.

## 错误、取消、内存与并发

- Invalid functional oracle, unequal workload or generator saturation invalidates benchmark.
- Do not declare Rust faster from a microbenchmark, language name or single favourable percentile.

## 验收要求

- All three routes with pinned binaries/config/data on Windows/Linux where equivalent; missing route explicitly explained.
- Predeclared regression bands grounded in baseline/noise, no guessed percentage target; raw data independently reviewed.
- Measure disabled Release, default Debug and explicit local Debug, sampled/full tracing, configured log/Meter sinks and exporter saturation/failure separately. Record allocations/native memory/CPU/callback latency/drop counts; scoped no-listener probe is not a product zero-cost claim.

- Windows x64; Linux x64
- ordinary dotnet build/run; for generators/analyzers this describes the produced consumer, not the compiler host; explicit-RID Native AOT publish and actual consumer execution on the required OS rows
- Independent NuGet where this component is distributed; full no-Rust pristine consumer gates A16/B24.
- Exact source/lock/features/native/package/executable hashes; component tests cannot claim assembled product success.
- The task-specific cases below plus D04–D09; native and managed retirement separately observed.

依赖理由：start pins only actually consumed completed modules; acceptance adds local assembled-runtime checks where required. Reference links alone never become a global barrier.
