## Implementation Steps

1. Create SQLx options from explicit configuration. Remote production default requires VerifyFull with trusted root and hostname; Prefer/Require are not verified TLS. Secret values never enter errors/manifest.
2. Implement real prepare/execute/stream over a fixed connection lease, parameter snapshots and structured SQLSTATE mapping, with bounded admission and statement cache policy.
3. Track ReadyForQuery synchronization and transaction status separately from the application result. Stream drop may need drain before reuse; enforce a cleanup deadline and retire a connection on failure.
4. Treat timeout/cancellation as a request. Do not invent a public SQLx cancel API from private cancel-key fields. Use explicit server statement_timeout/session policy where selected; cancellation cannot free an active task/connection.
5. Integrate B04 operation entrypoints; expose safe session-local provider hooks for B05, without sharing SQLx pointers across DLL boundaries.
6. Public API refinement 0.4.0: PostgreSqlDataSource/UsePostgreSql behavior over SQLx PostgreSQL; parameter, error, pool/session and capability mapping use B01 definitions.
7. Public API refinement 0.4.0: Use api_design_inputs and api_design_input_sha256 from the exact pinned Design commit; implement the declared member/type policies and native operation mapping. Update task-owned XML, generated API Reference contribution, guide and minimal/advanced consumer source together. For internal-only scopes document applicability and expose no accidental public plumbing.

## Errors, Cancellation, Memory, and Concurrency

- 57014 statement timeout inside a transaction leaves it failed (25P02) until rollback; Task completion is not reuse permission.
- After COMMIT dispatch without confirmation, report Unknown; connection close or successful cleanup rollback cannot prove original business rollback.
- SQLx Execute limit=0 is not server fetch batching. Application row/byte budgets do not prove a whole-process RSS bound or instantaneous server cancellation.
