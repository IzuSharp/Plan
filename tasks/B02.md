## 模块与接口

Own SQLx PostgreSQL provider in native/database/postgres and its narrow managed package; consume B01 seam, B07 binder and B05 transaction policy through B04, without implementing a second host/pool wrapper.

C# 接口：

Postgres-specific configuration/capability registration and structured provider details; the application still uses common Session/typed queries.

Rust 原生复用：

SQLx PgConnection/PgPool/Arguments, wire protocol and native TLS. SeaQuery-generated SQL is bound using B07. Do not recreate PostgreSQL protocol or publish Npgsql as a product path.

## 实施步骤

1. Create SQLx options from explicit configuration. Remote production default requires VerifyFull with trusted root and hostname; Prefer/Require are not verified TLS. Secret values never enter errors/manifest.
2. Implement real prepare/execute/stream over a fixed connection lease, parameter snapshots and structured SQLSTATE mapping, with bounded admission and statement cache policy.
3. Track ReadyForQuery synchronization and transaction status separately from the application result. Stream drop may need drain before reuse; enforce a cleanup deadline and retire a connection on failure.
4. Treat timeout/cancellation as a request. Do not invent a public SQLx cancel API from private cancel-key fields. Use explicit server statement_timeout/session policy where selected; cancellation cannot free an active task/connection.
5. Integrate B04 operation entrypoints; expose safe session-local provider hooks for B05, without sharing SQLx pointers across DLL boundaries.

## 错误、取消、内存与并发

- 57014 statement timeout inside a transaction leaves it failed (25P02) until rollback; Task completion is not reuse permission.
- After COMMIT dispatch without confirmation, report Unknown; connection close or successful cleanup rollback cannot prove original business rollback.
- SQLx Execute limit=0 is not server fetch batching. Application row/byte budgets do not prove a whole-process RSS bound or instantaneous server cancellation.

## 验收要求

- Use the real six PostgreSQL Design cases as regression oracles: timeout/rollback, early stream drop, codecs, response-loss durable COMMIT, conflict CTE snapshot and migration lock cleanup.
- Add product TLS negative tests: wrong hostname, untrusted root, expired chain and explicit plaintext-development opt-in; Windows/Linux AOT remote PG with actual server identity.
- Session reuse test must compare backend PID, not merely observe a subsequent query success. Broken/drain-timeout sessions are quarantined and pool permits eventually return.

- ['Windows x64', 'Linux x64']
- ['ordinary dotnet build/run; for generators/analyzers this describes the produced consumer, not the compiler host', 'explicit-RID Native AOT publish and actual consumer execution on the required OS rows']
- Independent NuGet where this component is distributed; full no-Rust pristine consumer gates A16/B24.
- Exact source/lock/features/native/package/executable hashes; component tests cannot claim assembled product success.
- The task-specific cases below plus D04–D09; native and managed retirement separately observed.
