## 目标与阶段

C# 是强类型应用层；数据库/ORM 查询关系和 Server 网络协议运行时必须由成熟 Rust 引擎实现。Kestrel/托管驱动只比较。普通 Entity/DTO/Handler 使用维护者预编译 native 模块，正常 dotnet build/run 与 AOT；不重写 C# SQL AST/方言/完整 LINQ，不引入强制巨型 Core runtime。

当前只执行 Research/Documentation 与 Design 研究原型；未来 Delivery 实施仍需明确阶段授权。设计接受不冒充产品、长负载或发布通过。

## 模块与接口

One domain-neutral idempotent task-service reference application, no ArcForges business dependency.

C# 接口：

Typed Task/Attempt/Lease entities, Fluent queries and C# Handler business logic on mandatory Rust DB/ORM/Server.

Rust 原生复用：

SQLx/SeaQuery and selected Rust host; use native transaction/relations/streaming implementation from B04/B14/B17.

## 实施步骤

1. Define deterministic schema/migrations and API operation semantics including idempotency key, CAS version and retryable outcomes.
2. Implement create/claim/complete/query flows with explicit transaction boundaries and native-backed typed Fluent calls.
3. Handle conflict CTE snapshot using a new statement when necessary; reconcile durable result after COMMIT Unknown before retry.
4. Exercise request/body/DB result streaming and correlation through C# Handlers, never Kestrel hosting.
5. Supply independent NuGet consumer profiles for SQLite and real PostgreSQL, including ordinary app model/Handler edits.

## 错误、取消、内存与并发

- ACK loss never blindly repeats a non-idempotent mutation; Unknown retained until durable reconciliation.
- Cancelled request cannot free live DB transaction/body owners; scope drains actual operations before release.

## 验收要求

- Real HTTP→C# Handler→Rust ORM/DB response on Windows/Linux AOT for both databases.
- Concurrent duplicate requests, conflict snapshot, crash/restart and durable reconciliation; native hash unchanged across ordinary entities.
