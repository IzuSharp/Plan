## 目标与阶段

C# 是强类型应用层；数据库/ORM 查询关系和 Server 网络协议运行时必须由成熟 Rust 引擎实现。Kestrel/托管驱动只比较。普通 Entity/DTO/Handler 使用维护者预编译 native 模块，正常 dotnet build/run 与 AOT；不重写 C# SQL AST/方言/完整 LINQ，不引入强制巨型 Core runtime。

当前只执行 Research/Documentation 与 Design 研究原型；未来 Delivery 实施仍需明确阶段授权。设计接受不冒充产品、长负载或发布通过。

## 实施步骤

1. Build native closure on declared baseline and record ELF architecture, exports and dynamic dependencies/glibc requirements.
2. Run ordinary RID-free NuGet consumer and explicit linux-x64 AOT outside source tree.
3. Transfer publish directory to runtime-only matching target environment; record absence of SDK/native toolchain needs at runtime.
4. Preserve source/lock/package/native/executable hashes, stdout/stderr and actual OS/CPU/linker identity.

## 错误、取消、内存与并发

- Wrong ELF/architecture/missing dependency/ABI fails deterministically; no downloading compiler at application startup.
- Static linking and broader distro support require separate profile evidence.
