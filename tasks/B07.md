## Modules and Interfaces

Sole owner of Rust logical-value to provider Arguments conversion and checked Rust/C# wire scalar conversion. B11 invokes this binder; do not duplicate it in query code or silently use a panic-prone convenience adapter.

C# interfaces:

ValueCodec<T>, Codecs and static RowReader/RowWriter accessors implement the canonical B01 declarations, exact db-wire scalar registry and fallible conversions; configured nullable/enum/JSON codecs are statically reachable. No object[] or auto-stringify fallback.

Rust native reuse:

SeaQuery Value/SQLx Encode/Type and provider native codecs; propagate every Arguments::add Result. Use explicit finite capability profiles.

## Implementation Steps

1. Implement the D14 finite scalar table with explicit size/range/endianness and NULL rules. UUID uses RFC/network bytes; distinguish CLR Guid layout.
2. Choose checked decimal domain and timestamp precision policy. PG arbitrary numeric is wider than rust_decimal; reject unrepresentable values. Reject sub-microsecond precision where the contract promises lossless conversion rather than silently truncating.
3. Use explicit SQLite decimal-as-text and timestamp profile rather than relying on dynamic SQLite affinity for precision. Nonfinite floats follow explicit backend capability policy.
4. Validate utf8, lengths, unknown tags, unsigned narrowing, encoded argument count/bytes before send; cleanup any partially constructed argument owner on failure.
5. Public API refinement 0.4.0: ValueCodec<T>/Codecs/parameter encoding and fallible native conversions; canonical definitions stay with B01, no parallel binder model.
6. Public API refinement 0.4.0: Use api_design_inputs and api_design_input_sha256 from the exact pinned Design commit; implement the declared member/type policies and native operation mapping. Update task-owned XML, generated API Reference contribution, guide and minimal/advanced consumer source together. ## Errors, Cancellation, Memory, and Concurrency

- A valid nullable slot containing SQL NULL differs from a missing column; shape preflight belongs to B06/B12.
- No unwrap/panic on user values; caught panic is exceptional containment, not normal codec validation.
- Cancellation can retire a pending operation only after input copies/leases are no longer used; argument buffer reuse is per execution.
