## 目标与阶段

当前只执行 Research/Documentation 与 Design 研究原型；未来 Delivery 实施仍需明确阶段授权。设计接受不冒充产品、长负载或发布通过。

## 模块与接口

Owned Body/Bytes budget and stream component; native/server/streaming is independent of host orchestration.

C# 接口：

- RequestBudget, owned ReadBodyAsync/WriteBodyAsync, Data/Trailers/End result; one pending read and one pending write.
- Native Body and retained allocation budget owners; configurable finite active/waiting/retiring request quotas.

Rust 原生复用：

- http-body/Bytes/Tokio bounded channels and owner-backed buffers; no managed protocol AST/runtime.

## 实施步骤

1. Implement checked global/per-request byte coordinator with atomic grants or rollback-safe try-acquire; reject impossible single-object credit requests.
2. Acquire credit before allocation/pin/copy; transfer charge with owner and retain full backing allocation charge through clones/nonempty slices.
3. Reserve bounded copy overlap slack on both sides; cancellation removes metadata waiters and returns uncommitted reservations.
4. Implement native Body bridge and C# safe lease facade over existing Core buffer/async; optional pipes facade cannot alter ownership.
5. Test the streaming crate/facade independently on real native Body/protocol fixtures; end-to-end assembled application/soak belongs to B22/B23.

## 错误、取消、内存与并发

- Response-head Future end, body EOF, backing allocation drop, callback retirement and OS join are different milestones.
- Receiver close does not revoke previously issued permits; close cancels/empties outstanding byte waits explicitly.
- ReferenceSmall uses4MiB/request/side,1MiB JSON and32KiB chunks; charge real capacity and reject impossible peaks rather than deadlock.

## 验收要求

- Normal dotnet build/run from an independent NuGet consumer without Rust installed; publish and execute win-x64 and linux-x64 Native AOT.
- No product implementation is authorized now; this is refinement of the existing 48 Delivery tasks.
- Use existing Core ABI/create-start/take-result/retire contracts; do not create another callback protocol or mandatory global runtime.
- No private upstream APIs exposed as stable ABI; pin Cargo/NuGet/features and reject incompatible native assets before callback registration.
- Retained Bytes slicing/drop, old permit across close, zero/huge lengths, copy overlap, cancellation at every ownership transition.
- Bounded queued metadata and charged bytes under slow producer/consumer; no RSS guarantee from item count.

- Windows x64; Linux x64
- ordinary dotnet build/run; for generators/analyzers this describes the produced consumer, not the compiler host; explicit-RID Native AOT publish and actual consumer execution on the required OS rows
- Independent NuGet where this component is distributed; full no-Rust pristine consumer gates A16/B24.
- Exact source/lock/features/native/package/executable hashes; component tests cannot claim assembled product success.
- The task-specific cases below plus D04–D09; native and managed retirement separately observed.

依赖理由：start pins only actually consumed completed modules; acceptance adds local assembled-runtime checks where required. Reference links alone never become a global barrier.
