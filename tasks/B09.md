## Implementation Steps

1. Define direct operation contracts for query create, predicates/joins/projection/order/limit, seal and execute plan reference, plus capability errors and legal state transitions.
2. Distinguish synchronous borrowed parameter input from copied/owned async arguments. A business descriptor hash is content identity, not Engine ABI fingerprint.
3. Bind owner identity and alias/type metadata to each operation. Raw ABI validation repeats type/capability/size checks; C# generics are not the only protection.
4. If implementing batches later, retain finite version/node/depth/bytes and prevalidate all operations before applying; failure cannot leave an executable partly mutated AST.
