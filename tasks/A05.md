## Implementation steps

1. Implement D08 exact status constants, complete ErrorRecord capacity algorithm and bounded UTF8 detail ownership.
2. Initialize every valid out-owner slot before fallible work; on error destroy unpublished state and translate without callbacks/reentrancy.
3. Contain exported Rust panics; handle caught payload destruction risk and poison the owning Engine after every contained native panic under D08; permit only explicitly trusted cleanup and never resume normal admission.
4. Catch managed Handler exceptions inside valid UCO entrypoints and preserve committed operation outcome; diagnostics cannot overwrite terminal results.
