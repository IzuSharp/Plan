## 目标与阶段

当前只执行 Research/Documentation 与 Design 研究原型；未来 Delivery 实施仍需明确阶段授权。设计接受不冒充产品、长负载或发布通过。

## 模块与接口

Optional execution/admission component only when an Engine needs it; no mandatory shared Tokio process runtime.

C# 接口：

Executor options/queue limits and lifecycle contract consumed explicitly by Engine.

Rust 原生复用：

Tokio runtime/JoinSet/semaphore/cancellation semantics; each Engine owns its configured runtime.

## 实施步骤

1. Implement Engine-local runtime handle or injected accepted executor profile with explicit ownership and thread counts.
2. Bound queued metadata, admitted work, byte reservations and retirement backlog separately; reject impossible requests immediately.
3. Shutdown closes admission, wakes/removes waiters, requests cancellation, drains tracked tasks and acknowledges actual worker retirement.
4. Expose timeout as incomplete safe cleanup and diagnostics, not force-destruction of active callbacks/buffers.

## 错误、取消、内存与并发

- Dropping a Tokio handle/Future does not prove spawn_blocking work or OS threads exited.
- Cancellation paths return permits/reservations exactly once; no unbounded background retry task.

## 验收要求

- Capacity zero/full/oversize, fairness and close-with-issued-permit races; actual join ack and retained-owner counters.
- Synchronous Engine package runs without constructing this component.

- Windows x64; Linux x64
- ordinary dotnet build/run; for generators/analyzers this describes the produced consumer, not the compiler host; explicit-RID Native AOT publish and actual consumer execution on the required OS rows
- Independent NuGet where this component is distributed; full no-Rust pristine consumer gates A16/B24.
- Exact source/lock/features/native/package/executable hashes; component tests cannot claim assembled product success.
- The task-specific cases below plus D04–D09; native and managed retirement separately observed.

依赖理由：start pins only actually consumed completed modules; acceptance adds local assembled-runtime checks where required. Reference links alone never become a global barrier.
