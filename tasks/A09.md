## 目标与阶段

C# 是强类型应用层；数据库/ORM 查询关系和 Server 网络协议运行时必须由成熟 Rust 引擎实现。Kestrel/托管驱动只比较。普通 Entity/DTO/Handler 使用维护者预编译 native 模块，正常 dotnet build/run 与 AOT；不重写 C# SQL AST/方言/完整 LINQ，不引入强制巨型 Core runtime。

当前只执行 Research/Documentation 与 Design 研究原型；未来 Delivery 实施仍需明确阶段授权。设计接受不冒充产品、长负载或发布通过。

## 模块与接口

Minimal binding-description IR, distinct from SQL/HTTP/domain AST.

C# 接口：

Immutable validated ABI/operation schema with deterministic identifiers and capabilities.

Rust 原生复用：

Reuse metadata/schema tooling and R05 exporter inventories; no new domain compiler.

## 实施步骤

1. Specify fixed layouts, import/export names, calling convention, nullability, borrow end, output transfer, thread/reentrancy, error and optional async profile.
2. Validate unsupported shapes and duplicate symbols before code generation; version schema independently of Engine business metadata.
3. Emit canonical deterministic description hash and full symbol inventory for A10/A11/drift tests.
4. Keep source provenance, generating tool version and handwritten/static-descriptor parity.

## 错误、取消、内存与并发

- Unsupported Rust tuples/generics cannot disappear silently from generated exports.
- No network/Cargo/database query runs inside compiler generators.

## 验收要求

- Same inputs produce identical IR across processes; malformed/unknown required fields fail with location-bearing diagnostics.
- Export inventory negative catches csbindgen silent omission case observed by R05.

- Windows x64; Linux x64
- ordinary dotnet build/run; for generators/analyzers this describes the produced consumer, not the compiler host; explicit-RID Native AOT publish and actual consumer execution on the required OS rows
- Independent NuGet where this component is distributed; full no-Rust pristine consumer gates A16/B24.
- Exact source/lock/features/native/package/executable hashes; component tests cannot claim assembled product success.
- The task-specific cases below plus D04–D09; native and managed retirement separately observed.

依赖理由：start pins only actually consumed completed modules; acceptance adds local assembled-runtime checks where required. Reference links alone never become a global barrier.
