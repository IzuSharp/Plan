## Implementation steps

1. Integrate generated context layout/golden validation and parent capture/restoration around actual native callbacks.
2. Instrument native futures with explicit owned dispatcher, never hold span.enter guard across await or seize global subscriber in a library.
3. Implement fixed-cardinality route/provider/category metrics and bounded attribute/event/queue bytes, with overflow drop counters.
4. Coordinate single monotonic request deadline and bounded close; expose ClosePending and continue retirement safely rather than free on timeout.
5. Flush optional exporters only after business owners close and within independent finite timeout; network export never blocks FFI callback or native lock.
6. Implement D19 explicit modes: Release/Debug install no listener/provider/global subscriber/exporter by default; optional application sink preset Warning/Error; IsEnabled/sampling before formatting; all correctness/retirement checks remain active.

## Errors, cancellation, memory and concurrency

- No listener avoids creating Activity/tags; sampling changes diagnostics only.
- Unknown DB commit remains Unknown during request timeout/shutdown; trace correlation is never identity/auth.
- Callback/retirement counts and process exit/OS join are distinct; stalled exporter cannot retain business resource ownership.
