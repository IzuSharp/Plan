## 模块与接口

Native and managed diagnostic context/deadline/shutdown coordination, reusing actual host/stream state.

C# 接口：

- TraceContextV1 size32/trace-id offset8/parent-span offset24; value metadata only, not Activity/GCHandle/span guard across FFI.
- ShutdownCoordinator monitors admission, response/body/retained bytes/permits/callback/runtime ownership and separate OS join.

Rust 原生复用：

- ActivitySource/Meter and optional bounded OpenTelemetry exporter; Rust tracing0.1.44 per-poll Instrumented/WithDispatch.

## 实施步骤

1. Integrate generated context layout/golden validation and parent capture/restoration around actual native callbacks.
2. Instrument native futures with explicit owned dispatcher, never hold span.enter guard across await or seize global subscriber in a library.
3. Implement fixed-cardinality route/provider/category metrics and bounded attribute/event/queue bytes, with overflow drop counters.
4. Coordinate single monotonic request deadline and bounded close; expose ClosePending and continue retirement safely rather than free on timeout.
5. Flush optional exporters only after business owners close and within independent finite timeout; network export never blocks FFI callback or native lock.

## 错误、取消、内存与并发

- No listener avoids creating Activity/tags; sampling changes diagnostics only.
- Unknown DB commit remains Unknown during request timeout/shutdown; trace correlation is never identity/auth.
- Callback/retirement counts and process exit/OS join are distinct; stalled exporter cannot retain business resource ownership.

## 验收要求

- Normal dotnet build/run from an independent NuGet consumer without Rust installed; publish and execute win-x64 and linux-x64 Native AOT.
- No product implementation is authorized now; this is refinement of the existing 48 Delivery tasks.
- Use existing Core ABI/create-start/take-result/retire contracts; do not create another callback protocol or mandatory global runtime.
- No private upstream APIs exposed as stable ABI; pin Cargo/NuGet/features and reject incompatible native assets before callback registration.
- Actual cross-language context golden/malformed fields and worker migration; repeat callbacks/cancel/dispose races.
- Exporter saturation/disconnect/block/timeout and no-secret assertions; disabled/sampled/full diagnostics cost from matched workloads.

- ['Windows x64', 'Linux x64']
- ['ordinary dotnet build/run; for generators/analyzers this describes the produced consumer, not the compiler host', 'explicit-RID Native AOT publish and actual consumer execution on the required OS rows']
- Independent NuGet where this component is distributed; full no-Rust pristine consumer gates A16/B24.
- Exact source/lock/features/native/package/executable hashes; component tests cannot claim assembled product success.
- The task-specific cases below plus D04–D09; native and managed retirement separately observed.

依赖理由：start pins only actually consumed completed modules; acceptance adds local assembled-runtime checks where required. Reference links alone never become a global barrier.
