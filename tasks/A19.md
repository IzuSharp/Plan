## 目标与阶段

C# 是强类型应用层；数据库/ORM 查询关系和 Server 网络协议运行时必须由成熟 Rust 引擎实现。Kestrel/托管驱动只比较。普通 Entity/DTO/Handler 使用维护者预编译 native 模块，正常 dotnet build/run 与 AOT；不重写 C# SQL AST/方言/完整 LINQ，不引入强制巨型 Core runtime。

当前只执行 Research/Documentation 与 Design 研究原型；未来 Delivery 实施仍需明确阶段授权。设计接受不冒充产品、长负载或发布通过。

## 实施步骤

1. Model logical admission/AddRef rollback, create/register/start, terminal ownership, take-once and native+managed retirement.
2. Encode unsafe legacy schedules as negative controls; retain counterexample trace and map each corrected transition to code owner.
3. Specify liveness fairness and bounded capacity explicitly; distinguish absence of finite counterexample from unbounded proof.
4. Run models independently of unfinished implementation; bind later refinement tests to exact implementation source.

## 错误、取消、内存与并发

- Timeout/state-space exhaustion is inconclusive, never passed.
- A model without real weak-memory semantics cannot prove all Rust/CLR races absent.
