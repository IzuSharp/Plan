## Implementation steps

1. Select smallest real HTTP operation profile with direct Rust oracle and one statically compiled foreign Handler.
2. Exercise create/register/start, completion/take/result ownership and two-sided retirement against actual native async I/O.
3. Implement finite byte/item/operation limits and close/drain semantics using common contracts; runtime stays Engine-local.
4. Package independently and record incremental adapter cost versus A17 synchronous Engine.

## Errors, cancellation, memory and concurrency

- Future completion is not Body or backing-Bytes retirement. Retained-byte capacity stays charged until the last backing owner releases it; the live-stream slot follows its separately defined Body/producer/handler completion predicate and is not the same permit.
- Abort/reset/cancel and late managed delivery cannot free callback roots early or lose terminal result.
