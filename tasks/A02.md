## 模块与接口

Engine-local loading, bootstrap and capabilities; no global service locator or universal function table.

C# 接口：

EngineModule/CapabilityProfile bootstrap with immutable supported-feature set.

Rust 原生复用：

OS native loader and D02 C ABI; optional function table only for an Engine that needs one.

## 实施步骤

1. Resolve packaged native assets through SDK-supported application-local loading; verify identity/RID/ABI and required capabilities.
2. Read only supported bootstrap prefixes; reject incompatible major and missing required bits without partial owners.
3. Support engine-prefixed fixed imports first; opt-in table validates every required pointer and retains module lifetime.
4. Keep module loaded for process lifetime and instances separately disposable; emit bounded Engine/version/RID diagnostics.

## 错误、取消、内存与并发

- Missing assets or unsupported feature never select a managed driver/host fallback.
- No unload while any call/callback/release can execute; unknown optional fields remain ignored/defaulted.

## 验收要求

- Old/new compatible minor and rejected major/capability/size combinations; wrong DLL/ELF/RID in isolated consumers.
- Two independent bootstrap fixture modules load without symbol collision or unwanted executor startup. Complete heterogeneous real Engine conformance belongs to A17/A18 and is not an A02 prerequisite.

- ['Windows x64', 'Linux x64']
- ['ordinary dotnet build/run; for generators/analyzers this describes the produced consumer, not the compiler host', 'explicit-RID Native AOT publish and actual consumer execution on the required OS rows']
- Independent NuGet where this component is distributed; full no-Rust pristine consumer gates A16/B24.
- Exact source/lock/features/native/package/executable hashes; component tests cannot claim assembled product success.
- The task-specific cases below plus D04–D09; native and managed retirement separately observed.

依赖理由：start pins only actually consumed completed modules; acceptance adds local assembled-runtime checks where required. Reference links alone never become a global barrier.
