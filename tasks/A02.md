## Implementation Steps

1. Resolve packaged native assets through SDK-supported application-local loading; verify identity/RID/ABI and required capabilities.
2. Read only supported bootstrap prefixes; reject incompatible major and missing required bits without partial owners.
3. Support engine-prefixed fixed imports first; opt-in table validates every required pointer and retains module lifetime.
4. Keep module loaded for process lifetime and instances separately disposable; emit bounded Engine/version/RID diagnostics.
