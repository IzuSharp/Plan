## Modules and Interfaces

Registration and revocation of statically compiled callbacks with explicit managed root lifetime.

C# interfaces:

Opaque registration token; static UnmanagedCallersOnly trampoline uses a cookie guaranteed live by the rooted registration and two-sided retirement protocol, not by probing an arbitrary nonzero GCHandle.

Rust native reuse:

Existing native wake/event hooks; one optional bridge, no reflection/delegate dynamic export.

## Implementation Steps

1. Implement registration state with active native invocations and queued/running managed deliveries counted separately.
2. Revocation closes admission then requests native quiescence; keep GCHandle/cookie until both native and managed counts retire.
3. Keep fixed terminal-notice bookkeeping bounded O(1). Ordinary notification validation/copy is bounded O(payload bytes) under declared byte/item limits, nonblocking and exception-contained; dispatch business handlers outside native locks. Explicit synchronous decision profiles follow D05 fail-closed and no-self-wait rules.
4. Handle registration failure, callback-before-return and final release through single owner-transfer rules.

## Errors, Cancellation, Memory, and Concurrency

- A pending ThreadPool item can outlive native callback return; native ack alone cannot free its cookie.
- Closing dispatcher must account for accepted queued work; no unbounded callback mailbox.
