## Modules and interfaces

One canonical fixed-layout C ABI description, independent of SQL/HTTP/GPU. Rust/C/C# records and status/storage widths must agree.

C# interfaces:

Internal blittable ABI records and engine-prefixed get_abi_v1 bootstrap; application code sees no raw pointers.

Rust native reuse:

Rust repr(C), C fixed-width declarations, .NET Sequential structs/LibraryImport; no Rust native ABI.

## Implementation steps

1. Implement D02 complete wire records, defined reserved fields, size/capacity negotiation and engine-prefixed symbols from one versioned description.
2. Generate sizeof/alignof/every-offset probes for C and Rust plus C# SizeOf/OffsetOf; archive actual output and compiler target.
3. Implement only scalar status plus out-pointer returns; document null/alias/alignment/borrow/output initialization for every export.
4. Bind layout/symbol inventory to source and ABI version; keep examples/goldens distinct from implementation-generated output.

## Errors, cancellation, memory and concurrency

- Null output or insufficient complete prefix writes nothing; no probe deliberately dereferences arbitrary invalid memory in the parent process.
- Never export bool, C long/wchar_t, Rust enums/Vec/Future, CLR references or unmanaged generic layouts.
