## Modules and Interfaces

Own optional incremental generator, its diagnostic fixtures and generated-output golden files only. B01/B09 own input contracts; B12 owns runtime/static reader behavior. Do not require this generator for ordinary querying.

C# interfaces:

The default facade-transitive Roslyn generator processes attributed C# models and emits statically referenced Table/Column metadata and RowMaterializer/EntityWriter methods. Explicitly excluding generators requires the documented equivalent manual static descriptors, never rd.xml, runtime discovery or a Rust rebuild.
