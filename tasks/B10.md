## 模块与接口

Own optional incremental generator, its diagnostic fixtures and generated-output golden files only. B01/B09 own input contracts; B12 owns runtime/static reader behavior. Do not require this generator for ordinary querying.

C# 接口：

Opt-in model/projection declarations emit immutable descriptors and static materializers equivalent to handwritten forms; direct C# constructor access is AOT-visible.

Rust 原生复用：

Roslyn incremental APIs only for static C# metadata/constructor emission; native SeaQuery/SQLx are unchanged application-independent assets.

## 实施步骤

1. Filter syntax then resolve explicit symbols; output deterministic fully-qualified names and ordering. No database connection, network, Cargo, source checkout or native compilation in generator execution.
2. Emit supported codec/nullability/key/alias/constructor descriptors and static DTO readers using B12 contract; closed generics/JsonTypeInfo are explicit.
3. Implement D17 NWQ0101–NWQ0106 family with exact location and meaning; preserve historical old diagnostic numbers rather than repurposing them.
4. Handle incremental invalidation for relevant model changes and stable unrelated changes. Do not rely on another generator output appearing in the same pass.

## 错误、取消、内存与并发

- Unsupported constructor/codec/type/nullability fails clearly with handwritten alternative only when it truly supports that model; no reflection fallback.
- Generated materialization always scopes the owned batch lease; constructor exceptions follow B12 cleanup.
