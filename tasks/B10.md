## Implementation Steps

1. Filter syntax then resolve explicit symbols; output deterministic fully-qualified names and ordering. No database connection, network, Cargo, source checkout or native compilation in generator execution.
2. Emit supported codec/nullability/key/alias/constructor descriptors and static DTO readers using B12 contract; closed generics/JsonTypeInfo are explicit.
3. Implement the complete D17 NWQ0101-NWQ0107 family with exact locations and meanings, including NWQ0107 for mappings requiring dynamic code or unbounded reflective discovery. Preserve historical old diagnostic numbers rather than repurposing them; test every diagnostic with a compile-negative fixture.
4. Handle incremental invalidation for relevant model changes and stable unrelated changes. Do not rely on another generator output appearing in the same pass.
