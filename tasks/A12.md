## Objective and phase

C# is the strongly typed application layer; Database/ORM queries and relations and the Server networking/protocol runtime must be implemented by mature Rust engines. Kestrel/managed drivers are comparators only. Ordinary Entity/DTO/Handler types use native modules precompiled by maintainers, with normal dotnet build/run and AOT; do not reimplement a C# SQL AST/dialects/full LINQ or introduce a mandatory monolithic Core runtime.

Only Research/Documentation and Design research prototypes are executed in the current phase; future Delivery implementation still requires explicit phase authorization. Design acceptance does not claim product, sustained-load or release validation has passed.

## Modules and interfaces

Static diagnostics for known ABI/AOT/ownership hazards; no assertion that analysis proves arbitrary unsafe code safe.

C# interfaces:

Actionable NW diagnostic IDs with source spans, severity, explanation and local fix where sound.

Rust native reuse:

Roslyn incremental analyzer/semantic model, framework AOT diagnostics; no runtime analysis service.

## Implementation steps

1. Implement D03 diagnostic set: unsupported wire types, invalid callback signatures, escaped borrow/ref-like values, missing required schema and conflicting export IDs.
2. Detect forbidden generator side effects/build hooks and unsupported dynamic reflection paths in owned surface where statically knowable.
3. Use compilation cancellation correctly and avoid retaining Compilation/Symbol graphs globally.
4. Document false-positive limits and narrow reviewed suppressions; unsupported uncertainty must not emit unsafe code.
