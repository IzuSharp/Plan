## Modules and Interfaces

Owned/borrowed byte regions and retained async leases; no allocator identity guessing.

C# interfaces:

CopyTo/ToArray and synchronous nonescaping scoped byte views under an active owner lease; async input uses bounded native copy or an explicitly accepted retained-owner/pin profile.

Rust native reuse:

Rust Vec/Bytes owners and source-verified destruction; D07 complete extent/stride contract.

## Implementation Steps

1. Implement D07 contiguous byte-view length/count/element-width and offset checks, checked u64↔nuint conversion, isize::MAX and allocation-capacity bounds; preserve null+zero rules. A strided view requires a separately accepted profile and is not part of v1.
2. Attach owner/type/release function to every allocation; copy/pin/borrow is an explicit profile with a defined end.
3. Hold owner and budget through clones/slices/async delivery; retain full backing allocation charge rather than visible slice length.
4. Dispose/pin release occurs after the last admitted consumer; mapper/conversion errors release all unpublished outputs.
5. Public API refinement 0.4.0: NativeBuffer, NativeBufferReader and maintainer NativeBufferFactory; scoped reads, explicit copies, async staging and release.
6. Public API refinement 0.4.0: Use api_design_inputs and api_design_input_sha256 from the exact pinned Design commit; implement the declared member/type policies and native operation mapping. Update task-owned XML, generated API Reference contribution, guide and minimal/advanced consumer source together. For internal-only scopes document applicability and expose no accidental public plumbing.

## Errors, Cancellation, Memory, and Concurrency

- Never create Span from untrusted extent before validation; no CLR free of Rust memory or cross-CRT ownership.
- Cancel/timeout/Body EOF does not revoke another live buffer lease.
- The initial public surface is CopyTo/ToArray or a synchronous nonescaping scoped view with an active lease; do not expose arbitrary native-backed Memory/MemoryManager or a Span after dropping its owner lease.
