## 模块与接口

Owned/borrowed byte regions and retained async leases; no allocator identity guessing.

C# 接口：

Read-only borrowed span for synchronous use; owned result/MemoryManager with explicit disposal and safe async retention.

Rust 原生复用：

Rust Vec/Bytes owners and source-verified destruction; D07 complete extent/stride contract.

## 实施步骤

1. Implement checked bounds/stride extent and u64↔nuint conversion against native allocation capacity; preserve zero-length rules.
2. Attach owner/type/release function to every allocation; copy/pin/borrow is an explicit profile with a defined end.
3. Hold owner and budget through clones/slices/async delivery; retain full backing allocation charge rather than visible slice length.
4. Dispose/pin release occurs after the last admitted consumer; mapper/conversion errors release all unpublished outputs.

## 错误、取消、内存与并发

- Never create Span from untrusted extent before validation; no CLR free of Rust memory or cross-CRT ownership.
- Cancel/timeout/Body EOF does not revoke another live buffer lease.

## 验收要求

- Property oracle using arbitrary precision plus native/C# parity for zero/huge/negative-stride/overflow extents.
- Retained slices, copy overlap, malformed descriptor, GC/Dispose races and creating-module release count on each OS AOT.

- ['Windows x64', 'Linux x64']
- ['ordinary dotnet build/run; for generators/analyzers this describes the produced consumer, not the compiler host', 'explicit-RID Native AOT publish and actual consumer execution on the required OS rows']
- Independent NuGet where this component is distributed; full no-Rust pristine consumer gates A16/B24.
- Exact source/lock/features/native/package/executable hashes; component tests cannot claim assembled product success.
- The task-specific cases below plus D04–D09; native and managed retirement separately observed.

依赖理由：start pins only actually consumed completed modules; acceptance adds local assembled-runtime checks where required. Reference links alone never become a global barrier.
