## Source and identity chain

The freeze requires full 40-character commit IDs and resolves their actual Git
trees. Both provider plans must be exact transformations of the original
generator output by the already reviewed selector, with candidate and Dapper
as the measured cohorts. The fixture retains its separate unmeasured role. The
runner and manifest bytes must match the selected source commit. The selected
output directories must not exist when the freeze is created.

For each consumer, the script binds the build receipt, exact committed C# source
inventory, project, `global.json`, generated C# inventory, package identities,
and publish output. The producer command must be Release Native AOT for
`linux-x64`; the executable must have a Linux x64 ELF header and no companion
`<executable>.dll`. The existing consumer reader independently checks successful
build status, provider, manifest, project hash and executable hash. Candidate
consumers retain zero project references and an independent provider package.

For Korda, the release receipt must identify the selected clean product commit
and tree. Its package digest is checked against the restored archive, every
unsigned archive member is rehashed, the `.nuspec` repository commit must
match, and the packaged native member's source/RID/hash must match the native
image listed in the consumer receipt and published output. Thus a release
description alone cannot stand in for the actual package or loaded image.

For Dapper, the restored package graph is bound to its archived package bytes.
The matched lifecycle SQL policy, static contract, and actual generated factory
proof are independently recomputed using the fixed validator source. The
historical Dapper receipt **does not contain `builder_sha256`**: `builderSource`
therefore identifies the selected committed builder file, not independently
the builder process run at the time. Its source/project/contract/package/ELF
chain remains checked against the preserved receipt. No runtime wire trace is
inferred from the generated-factory proof.

The audit rebuilds the complete frozen binding and requires the identical input
inventory and hashes, then repeats the final read checks. It does not trust an
edited embedded binding simply because the freeze document has a new hash.

## Raw owner and execution checks

Every Korda raw result must state Native AOT, the exact public Fluent route,
package version, executable digest and loaded native path/digest. It must
declare returned-to-zero and contain all eight counters as actual JSON
integers equal to zero: Sources, Sessions, Operations, Cursors, Buffers, Owners,
PullChannels and CommandCompletions. Missing values, booleans, floats, strings,
negative values, positive leaks and malformed containers are rejected.

Dapper must report its exact route and locked Dapper/AOT/provider versions,
the bound ELF digest, and an integer-zero ApplicationConnections counter with
its returned-to-zero declaration. SQLite binds the separately selected SQLite
library; the Npgsql result must report no native image. Cross-provider and
cross-cohort raw images fail the independent controls.

The auditor requires exactly the four provider/cohort final observations. It
recomputes the retained arithmetic report from the original index and raw
inputs, rather than trusting stored booleans or metrics. That analyzer remains
responsible for 1800-second coverage, the 35-case mix, counter arithmetic,
business assertions, serial intervals and recorded idle. The supplement then
ties each eligible observation to the frozen command/plan, actual successful
invocation, affinity, options and database identity. A fixture cannot be selected
as a measured final command. The bound PostgreSQL server executable, data path,
affinity and port must agree with its owner receipt and measured connection.

This supplement does not decide host load qualification, performance benefit,
business/framework allocation separation or task completion. Those require the
actual current-candidate experiment and its substantive analysis. The older
arithmetic report deliberately remains responsible for the duration and
performance computations; this review did not replace it with synthetic final
data.
