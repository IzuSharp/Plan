```csharp
public sealed class NativeWeaveAnalyzer : DiagnosticAnalyzer
```

**summary:** Reports statically identifiable NativeWeave ABI, lifetime, generation, AOT and API hazards.

**remarks:** This compiler plug-in consumes explicit AdditionalFiles and semantic source information. It never loads a native engine, starts a process or accesses the network. Analysis is concurrent and cancellable; per-compilation state is released with that compilation. No application runtime API is introduced. The absence of diagnostics does not prove arbitrary unsafe code or concurrent retirement correct.
